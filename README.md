# 🎮 github-aman-games (Aman's Arcade)

A premium, fully responsive, and sound-synthesized gaming hub hosted for free on GitHub Pages.

## 🕹️ Included Games
1. **Tic Tac Toe**: Local multiplayer or vs AI (Easy, Medium, and Unbeatable Minimax difficulties).
2. **Memory Flip**: 3D card flips, retro emojis, moves tracker, and stopwatch.
3. **Reaction Speed**: Accurate millisecond click timer with average score logs.

## ⚡ Tech Stack & Features
- **Core**: Vanilla HTML5, high-performance CSS3, and JavaScript.
- **Sound**: Real-time programmatically synthesized retro sounds using the **Web Audio API** (no downloads required, mute toggle synced globally).
- **Style**: Neon dark glassmorphism theme with smooth SVG/CSS animations.
- **Storage**: Scoreboards and records saved locally via `localStorage`.

## 🚀 Local Preview
To preview locally:
1. Open terminal and run:
   ```bash
   python3 -m http.server 8000
   ```
2. Navigate to `http://localhost:8000`.
